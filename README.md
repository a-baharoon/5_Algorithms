# Algorithms – Level 2
## Overview

This repository contains 50 *still* easy problems, all solved using the Divide and Conquer strategy, but with a different problem-solving style compared to Level 1 (more dividing, some input validation, writing general functions etc.).

The repository includes my solutions to all fifty problems. As with previous levels, some solutions may have been copied from the instructor after solving them on my own, purely for learning and reinforcement purposes.

**In addition, this level includes two simple projects that provide a powerful learning experience in how to properly divide a problem into manageable parts and conquer it step by step.**

**Project 1: Console Rock Paper Scissors**
**Project 2: Math Quiz Game**

### Notes
There may be slight differences in how programs are presented, which comes down to personal preference—the core logic and final results remain the same.

## Key Takeaway
- Do not start writing any code before explicitly mapping out your solution. (learnt it the hard way from projects)
- This level strongly emphasized planning, clarity of thought, and structured problem decomposition before implementation.
